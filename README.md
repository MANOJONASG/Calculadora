# Calculadora

Calculadora web simples e moderna, com histórico de cálculos e tema claro/escuro.

![Calculadora](assets/Screenshot.png)

## Funcionalidades

- Operações básicas: soma, subtração, multiplicação e divisão
- Porcentagem (`%`), inversão de sinal (`+/−`) e raiz quadrada (`√`)
- Histórico de cálculos, com opção de reutilizar um resultado e botão para limpar
- Alternância entre tema claro e escuro
- Suporte a teclado

## Atalhos de teclado

| Tecla   | Ação            |
| ------- | --------------- |
| `Enter` | Calcular        |
| `⌫`     | Apagar          |
| `Esc`   | Limpar          |
| `F9`    | Inverter sinal  |
| `R`     | Raiz quadrada   |
| `%`     | Porcentagem     |

## Como usar

1. Clone o repositório:
   ```bash
   git clone <url-do-repositorio>
   ```
2. Abra o arquivo `index.html` no navegador.
